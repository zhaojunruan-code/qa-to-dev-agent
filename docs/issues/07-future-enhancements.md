# 后续增强 Issue

## 背景

MVP 发布后需要规划增强方向，提升上下文理解和协作自动化能力。

## 目标

形成后续迭代 backlog。

## 范围

- 代码定位增强。
- 多轮澄清。
- 远程 Issue API。
- Eval harness。
- 文档链接解析增强。

## 具体任务

- 设计更强的文件匹配和调用链摘要。
- 支持 GitHub/GitLab token 或 connector API。
- 增加生成质量评估集。
- 支持输出模板配置。

## 验收标准

- 增强项独立成 Issue。
- 不破坏 MVP 只读原则。

## 风险点

- 深度扫描可能读取过多无关或敏感文件。

## 待确认问题

- 优先做 GitHub/GitLab API 还是语义扫描增强。
