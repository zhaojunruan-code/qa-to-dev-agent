# 测试计划 Issue

## 背景

MVP 发布前需要验证 CLI、输出结构、安全边界和错误路径。

## 目标

确认 QA-to-Dev Prompt Agent 满足可发布的 P0 标准。

## 范围

- CLI 参数。
- 项目扫描。
- 本地生成。
- Prompt 预览。
- Markdown 输出。
- Issue fallback。
- README 示例。

## 具体任务

- 验证正常输入。
- 验证空输入。
- 验证不存在项目路径。
- 验证固定章节。
- 验证文档链接失败说明。
- 验证本地 Issue Markdown。

## 验收标准

- P0 测试用例全部通过。
- 失败路径有明确错误提示。
- 没有修改被分析项目的业务代码。

## 风险点

- 无法在本地验证所有 provider 的 LLM 兼容性。

## 待确认问题

- 是否需要接入 CI。
