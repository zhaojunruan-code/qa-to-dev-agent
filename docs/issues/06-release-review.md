# 审核发布 Issue

## 背景

MVP 完成后需要审核是否达到发布标准。

## 目标

确认没有 P0/P1 阻塞问题，并记录发布风险。

## 范围

- MVP 范围符合性。
- 只读原则。
- 安全边界。
- 测试结果。
- README 完整性。
- Issue 和文档沉淀。

## 具体任务

- 审查功能清单。
- 审查测试结果。
- 审查已知限制。
- 给出发布结论。

## 验收标准

- `docs/release-review.md` 已生成。
- 审核结论明确。
- 发布阻塞问题为 0。

## 风险点

- 静态扫描深度不足可能影响任务质量。

## 待确认问题

- 是否需要发布版本号和 tag。
