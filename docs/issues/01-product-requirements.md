# 产品需求 Issue

## 背景

QA-to-Dev Prompt Agent 面向测试工程师，把简略修改说明、验收目标、问题描述和补充材料转换为开发工程师或 Codex CLI 可执行的结构化开发任务。

## 目标

交付一个默认只读的 CLI MVP，降低 QA 到 Dev 的需求表达损耗。

## 范围

- CLI 输入 QA 描述和目标项目路径。
- 只读扫描项目上下文。
- 生成结构化开发任务和 Codex CLI Prompt。
- 支持本地 Markdown 输出和 Issue 备份。

## 具体任务

- 明确 MVP 和非 MVP 边界。
- 定义用户角色、核心流程、功能模块。
- 固定输出 Markdown 结构。

## 验收标准

- 产品计划文档已生成。
- README 说明产品定位、安全原则和使用方式。
- 后续开发 Issue 有清晰范围。

## 风险点

- 用户可能误解为自动编码工具。
- 静态扫描不能保证完整调用链。

## 待确认问题

- 是否需要双语输出。
- 是否需要默认保存历史生成记录。
